## Troll mode

This is an exclusive feature in my app thats makes it unique from any other to-do app. 

Troll mode have two feature as of now — 

`Jumpscare` - The app would give you random jumpscare if you have any incomplete task past its due time.

`Closing_Window` This feature would close the app/path that you are using if you have added it in blacklisted list.
